# ТЗ на дизайн — «Мобильный кабинет Продавца» (RSD)

> Техническое задание для генерации UI/UX дизайна приложения.
> Формат: mobile-first PWA. Основная платформа — смартфон (375–430px).
> Админские роли также используются с мобильного устройства.

---

## 1. О продукте

**Название:** Мобильный кабинет Продавца
**Тип:** PWA (Progressive Web App), mobile-first
**Назначение:** Корпоративная платформа для сети розничных точек. Объединяет обучение персонала, отслеживание продаж, рейтинги и мотивацию в одном мобильном приложении.

**Целевая аудитория:**
- Продавцы розничных точек (18–45 лет, используют приложение со смартфона ежедневно)
- Менеджеры и руководители (30–55 лет, просматривают отчёты и рейтинги)
- Администраторы (25–50 лет, загружают данные и управляют контентом)

**Ключевые сценарии:**
- Продавец открывает приложение перед/после смены → видит свой план, рейтинг, новые назначенные тесты
- Продавец проходит обучение и тесты в свободное время
- Менеджер/руководитель проверяет показатели блока точек
- Администратор загружает планы продаж или новые материалы обучения

---

## 2. Визуальный стиль

### Общая концепция
Чистый, современный, профессиональный интерфейс. Без перегрузки деталями — продавцы используют приложение «на ходу», между клиентами. Информация должна считываться за секунды.

### Настроение
- Деловое, но не скучное
- Мотивирующее (рейтинги, прогресс, достижения)
- Лёгкое для восприятия (большие тапабельные зоны, читаемые шрифты)

### Цветовая палитра

| Назначение | Цвет | Использование |
|------------|-------|---------------|
| Основной (Primary) | Глубокий синий (#1A56DB или аналог) | Кнопки, активные элементы, навигация |
| Акцентный (Accent) | Яркий зелёный (#22C55E или аналог) | Успех, выполнение плана, прогресс |
| Предупреждение | Янтарный (#F59E0B) | Дедлайны, частичное выполнение |
| Ошибка / опасность | Красный (#EF4444) | Ошибки, невыполнение, удаление |
| Фон основной | Светло-серый (#F8FAFC) | Фон экранов |
| Фон карточки | Белый (#FFFFFF) | Карточки, модальные окна |
| Текст основной | Тёмно-серый (#1E293B) | Заголовки, основной текст |
| Текст вторичный | Серый (#64748B) | Подписи, метаданные |

### Типографика
- Заголовки: 20–24px, semi-bold / bold
- Подзаголовки: 16–18px, medium
- Основной текст: 14–16px, regular
- Мелкий текст (caption): 12px, regular
- Шрифт: Inter или аналогичный геометрический sans-serif

### Скругления и тени
- Скругления карточек: 12–16px
- Скругления кнопок: 10–12px
- Скругления инпутов: 8–10px
- Тени карточек: мягкие, 0 2px 8px rgba(0,0,0,0.06)

### Отступы
- Боковые отступы экрана: 16px
- Расстояние между карточками: 12px
- Внутренние отступы карточки: 16px

### 4.2 Продавец

#### Главная (Дашборд)
**Шапка:** аватар + имя + уровень (бейдж)

**Карточка «План на сегодня»:**
- Круговой прогресс-индикатор (% выполнения плана)
- Числовые значения: план / факт
- Подпись: «Ежедневный стакан»

**Карточка «Обучение»:**
- Линейный прогресс-бар (% пройденных курсов)
- Текст: «Осталось N курсов / тестов»
- Кнопка «Продолжить»

**Карточка «Рейтинг»:**
- Позиция в рейтинге (большая цифра)
- Мини-график изменения позиции (стрелка вверх/вниз)
- Подпись: «Среди N продавцов блока»

**Блок уведомлений:**
- Список из 2–3 последних уведомлений (иконка + текст + время)
- Ссылка «Все уведомления»

#### База знаний
**Список разделов** (4 карточки в виде плиток 2×2 или вертикального списка):
1. Организация работы (иконка: Briefcase)
2. Скрипты (иконка: MessageSquare)
3. Описание продуктов (иконка: Package)
4. Технологические карты (иконка: ClipboardList)

Каждая плитка: иконка + название + счётчик «N материалов» + прогресс прохождения

#### Экран раздела базы знаний
- Заголовок раздела
- Список курсов/материалов (карточки):
  - Иконка типа (текст / видео / документ)
  - Название
  - Длительность / объём
  - Статус: «Пройден» ✓ / «В процессе» / «Не начат»
  - Прогресс-бар (если в процессе)

#### Экран материала
- Заголовок
- Контент: текст с изображениями, видеоплеер, слайдер медиа
- Кнопка «Пройден» / «Далее» внизу (фиксированная)

#### Экран списка тестов
- Список тестов по разделу:
  - Название теста
  - Количество вопросов
  - Статус: «Пройден (85%)» / «Назначен» / «Повторный»
  - Дедлайн (если есть)

#### Экран прохождения теста
- Прогресс вверху: «Вопрос 3 из 15» + прогресс-бар
- Текст вопроса
- Варианты ответа (radio-кнопки или чекбоксы)
- Кнопка «Далее» (фиксирована внизу)
- Таймер (если ограничение по времени)

#### Экран результата теста
- Большой круговой индикатор с результатом (%)
- Цвет: зелёный (сдан) / красный (не сдан)
- Текст: «Тест пройден!» или «Попробуйте ещё раз»
- Статистика: правильных / неправильных
- Кнопка «К списку тестов» / «Пройти заново»

#### Продажи
**Табы:** Ежедневный стакан | Периодический стакан

**Содержимое таба:**
- Круговой или полукруговой индикатор: план / факт
- Вертикальная столбчатая диаграмма (последние 7 дней или текущий период)
- Карточка «Мотивация»: расчётная сумма бонуса за текущий период
- Детализация (аккордеон): список позиций с план/факт по каждой

#### Рейтинг
**Табы:** По продажам | По обучению

**Карточка «Моя позиция»:**
- Крупная цифра позиции (с анимацией)
- Изменение за период (↑3 или ↓2)
- Аватар, имя, значение метрики

**Список рейтинга:**
- Топ-10 (или весь блок) — список с:
  - Позиция (1, 2, 3 — с медалями 🥇🥈🥉)
  - Аватар
  - Имя
  - Значение метрики
  - Текущий пользователь выделен фоном

#### Профиль
- Аватар (с кнопкой «Изменить фото»)
- ФИО
- Должность, точка
- Уровень + прогресс до следующего
- Блок достижений / наград (горизонтальный скролл карточек)

**Пункты меню (список):**
- Моё расписание
- Мои отпуска и отгулы
- История достижений
- Уведомления
- О приложении
- Выйти

#### Расписание (из профиля)
- Календарь (месячный вид) с отмеченными сменами
- Цвета дней: смена (синий), выходной (серый), отпуск (зелёный), отгул (жёлтый)
- Под календарём: детализация выбранной недели (список дней с временем смен)

### 4.3 Менеджер блока / куста

#### Дашборд
**Шапка:** имя + роль + название блока

**Карточка «Выполнение плана»:**
- Общий % по блоку (круговой индикатор)
- Мини-список точек с прогресс-барами

**Карточка «Обучение»:**
- % сотрудников, прошедших обязательные курсы
- Количество просроченных тестов

**Карточка «Рейтинг блока»:**
- Позиция блока среди других блоков

#### Отчёты
**Каталог отчётов** (список карточек):
- Мотивация по ежедневному стакану
- Мотивация по периодическому стакану
- Сводный отчёт по продажам
- Прогресс обучения

Каждая карточка: название + описание + кнопка «Открыть»

#### Экран отчёта
- Заголовок + период (выбор периода — date picker)
- Таблица или список с данными
- Кнопка «Выгрузить» (если разрешено для роли)

#### Сотрудники
- Поиск (инпут вверху)
- Фильтр по точке (горизонтальные табы)
- Список сотрудников (карточки):
  - Аватар
  - ФИО
  - Точка
  - Ключевой показатель (% плана или % обучения)

#### Карточка сотрудника
- Аватар + ФИО + должность
- Табы: Продажи | Обучение | Расписание
- В каждом табе — соответствующие данные (план/факт, прогресс курсов, график смен)

### 4.5 Администратор Обучение

#### Главная
- Счётчики: материалов в базе, активных тестов, назначенных курсов, просроченных
- Последние действия (лог)

#### Управление → База знаний
- Дерево разделов (аккордеон: раздел → курсы → материалы)
- Кнопка «+ Добавить материал» (FAB или кнопка вверху)
- Каждый элемент: название + тип + статус (опубликован / черновик) + действия (edit, delete)

#### Экран создания / редактирования материала
- Поле «Заголовок»
- Выбор раздела (dropdown)
- Rich-text редактор (панель форматирования: жирный, курсив, список, ссылка)
- Загрузка изображений (drag & drop зона или кнопка)
- Загрузка видео
- Кнопка «Сохранить как черновик» / «Опубликовать»

#### Управление → Тесты
- Список тестов (карточки):
  - Название
  - Раздел
  - Количество вопросов
  - Тип (промежуточный / итоговый / повторный)
  - Статус (активен / неактивен)
- Кнопка «+ Создать тест»

#### Экран создания теста
- Название теста
- Привязка к разделу
- Настройки: время на тест, количество попыток, проходной балл
- Список вопросов (drag & drop сортировка):
  - Текст вопроса
  - Варианты ответа (radio / checkbox)
  - Отметка правильного ответа
  - Кнопка «+ Добавить вопрос»
- Кнопка «Сохранить»

#### Назначение обучения
- Выбор: курс или тест (dropdown)
- Выбор получателей: по сотруднику / по точке / по блоку / всем
- Дедлайн (date picker)
- Кнопка «Назначить»

#### Отчёты
- Рейтинг по обучению (таблица сотрудников с % прохождения)
- Фильтры: период, блок, точка
- Выгрузка в файл

### 4.6 Администратор Продажи

#### Главная
- Счётчики: загружено планов, обработано данных, расчёт мотивации (статус)
- Уведомления о незагруженных данных

#### Управление → Планы продаж
**Табы:** Ежедневный стакан | Периодический стакан

- Выбор периода (месяц/неделя)
- Таблица: точка → план → статус загрузки
- Кнопка «Загрузить данные» (файл xlsx/csv)
- Индикатор: загружено / не загружено по каждой точке

#### Экран загрузки данных
- Зона drag & drop для файла
- Или кнопка «Выбрать файл»
- Превью данных после загрузки (таблица)
- Валидация: ошибки подсвечены красным
- Кнопка «Подтвердить загрузку»

#### Управление → Мотивация
- Выбор периода
- Таблица: сотрудник → план → факт → % выполнения → сумма мотивации
- Статус расчёта: «Рассчитано» / «Требует данных»
- Кнопка «Пересчитать»

#### Отчёты
- Рейтинг по продажам
- Сводный отчёт по мотивации
- Фильтры: период, блок, точка
- Выгрузка

### 4.7 Администратор Персонал

#### Главная
- Счётчики: всего сотрудников, на смене сегодня, в отпуске, вакансий
- Ближайшие события (окончание отпусков, дни рождения)

#### Управление → Сотрудники
- Поиск + фильтры (блок, точка, статус)
- Список сотрудников (карточки):
  - Аватар + ФИО
  - Точка + должность
  - Статус: на смене / выходной / отпуск
- Кнопка «+ Добавить сотрудника»

#### Экран создания / редактирования профиля
- Фото (загрузка)
- ФИО
- Контактные данные (телефон, email)
- Должность (dropdown)
- Точка / блок (dropdown)
- Дата приёма
- Данные по оплате (ставка, коэффициенты) — скрываемый блок
- Кнопка «Сохранить»

#### Управление → Табель-графики
- Выбор точки (dropdown)
- Выбор периода (неделя / месяц)
- Табличный вид: сотрудники × дни
- Ячейки: время начала—конца смены или статус (В — выходной, О — отпуск)
- Кнопка «Загрузить график» (файл)
- Редактирование ячейки по тапу (popup: выбор типа дня + время)

#### Управление → Отсутствия
- Список текущих отсутствий
- Фильтры: тип (отпуск / отгул / больничный), блок, точка
- Кнопка «+ Оформить отсутствие»
- Форма: сотрудник, тип, даты, комментарий

### 4.8 Администратор ПО

- Список всех аккаунтов (с фильтрами по роли и статусу)
- Карточка аккаунта: аватар + ФИО + роль (бейдж цветом) + статус (активен / заблокирован)
- Кнопка «+ Создать аккаунт»

#### Экран создания аккаунта
- ФИО

  - Дата/время

- Каталог всех отчётов системы
- Фильтры: тип (продажи / обучение / кадры), период

- Всего точек / блоков

- Активных аккаунтов

**Карточка «Продажи по сети»:**
- Общий % выполнения плана (индикатор)
- Топ-3 и худшие-3 блока (мини-список)

**Карточка «Обучение по сети»:**
- % прохождения обязательного обучения
- Количество просроченных тестов

**Карточка «Рейтинги»:**
- Быстрые ссылки: рейтинг блоков по продажам, рейтинг по обучению

#### Структура сети
- Дерево: Блоки → Кусты → Точки
- Каждый элемент раскрывается (аккордеон)
- Информация по точке: адрес, менеджер, количество продавцов
- Кнопки: редактировать, добавить блок/куст/точку

#### Настройки
- Формулы расчёта мотивации (поля с коэффициентами)
- Лимиты аккаунтов по ролям (числовые поля)
- Назначение Администраторов ПО (список + кнопка «Назначить»)
- Системные параметры

## 8. Требования к адаптивности

| Breakpoint | Описание |
|------------|----------|
| 320–430px | Основной мобильный вид (приоритет) |
| 431–768px | Планшет (опционально, те же экраны с большими карточками) |

## 9. Дополнительные указания

- **Тёмная тема** — не требуется на данном этапе
- **Анимации** — минимальные, нативные (переходы между экранами, раскрытие аккордеонов, прогресс-индикаторы)
- **Иконки** — линейные (outline), единый стиль, набор Lucide или аналогичный
- **Иллюстрации** — простые flat-иллюстрации для empty states и экрана результата теста
- **Язык интерфейса** — русский
