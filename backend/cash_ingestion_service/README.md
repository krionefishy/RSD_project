# cash_ingestion_service

Микросервис приема событий продаж от кассовых систем.

Правила:

- сервис имеет свою БД и свои Alembic миграции;
- входящие продажи сохраняются локально для аудита, идемпотентности, повторной доставки и аналитики;
- дальнейшая доставка идет через shared Kafka, не через поток HTTP-запросов в основной сервис;
- Kafka/S3/Redis используются из общего shared-инфраструктурного слоя;
- сервис пока не подключен к docker compose.

Текущий stub API:

```text
POST /api/v1/sales/ingest
```

Endpoint сохраняет входящую продажу и публикует событие `cash.sales.received` в Kafka.
