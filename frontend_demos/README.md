# frontend_demos — Demo 1 (частично моковый UI)

Отдельная копия фронтенда для демонстрации **Этапа 6**: live backend только для auth и кадров (`admin-personnel`), остальные модули — дизайн-моки.

Основной `frontend/` для разработки **не трогаем** — синхронизация с ним вручную по мере необходимости.

## Локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой

См. `deploy/docker-compose.demo1.yaml` и `docs/DEMO1_BRANCH_RUNBOOK.md`.
