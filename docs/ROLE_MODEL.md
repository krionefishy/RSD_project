# Ролевая модель — «Мобильный кабинет Продавца»

> Описание ролей, иерархии и функционала, доступного каждой роли в системе RSD.

---

## 1. Иерархия ролей

```
СуперАдмин (Super Admin)
└── Администратор ПО           (назначается СуперАдмином)
    ├── Администратор Персонал     (до 3 аккаунтов)
    ├── Администратор Обучение     (до 2 аккаунтов)
    ├── Администратор Продажи      (до 3 аккаунтов)
    ├── Руководитель               (до 10 аккаунтов)
    ├── Менеджер блока / куста     (до 15 аккаунтов)
    └── Продавец                   (до 450 аккаунтов)
```

**Принцип наследования прав:** каждая роль выше в иерархии имеет доступ к просмотру данных подчинённых ролей в пределах своей зоны ответственности. Редактирование и управление — только по явно закреплённому функционалу.

---

## 2. Области видимости данных

| Роль | Область видимости |
|------|-------------------|
| СуперАдмин | Полный доступ ко всем данным, ролям и настройкам системы |
| Администратор ПО | Управление аккаунтами, контроль загрузки данных и отчётов |
| Администратор Персонал | Профили, графики и кадровые данные всей сети |
| Администратор Обучение | Материалы, тесты и результаты обучения всей сети |
| Администратор Продажи | Планы продаж, факт и мотивация всей сети |
| Руководитель | Данные по подчинённым точкам/блокам (до 10 точек) |
| Менеджер блока / куста | Данные по своему блоку / кусту точек |
| Продавец | Собственные данные: продажи, обучение, рейтинг |

## 3. Описание ролей и функционал

### 3.1 СуперАдмин (Super Admin)

**Описание:** Владелец системы с неограниченным доступом. Видит все данные по всей сети, управляет ролью Администратора ПО и контролирует работу системы на верхнем уровне.

#### Полный просмотр данных
- Просмотр всех блоков точек (кустов) и их показателей
- Просмотр всех рейтингов: по продажам, обучению, мотивации
- Просмотр всех отчётов системы без ограничений
- Просмотр профилей и данных любого пользователя системы
- Просмотр результатов тестирования и обучения всех сотрудников

#### Управление ролями
- Назначение и снятие роли Администратора ПО
- Просмотр списка всех аккаунтов и их ролей
- Блокировка любого аккаунта в системе

#### Контроль системы
- Просмотр логов действий всех пользователей
- Просмотр статистики использования системы
- Управление глобальными параметрами и настройками
- Настройка структуры сети (блоки, кусты, точки)
- Настройка формул расчёта мотивации

#### Отчёты
- Просмотр и выгрузка любых отчётов (продажи, обучение, кадры)
- Создание шаблонов отчётов
- Настройка периодичности автоматических отчётов

---

### 3.2 Администратор ПО

**Описание:** Операционный администратор системы. Создаёт и управляет аккаунтами всех ролей (кроме СуперАдмина), контролирует загрузку данных и формирование отчётов.

#### Управление аккаунтами
- Создание, блокировка и удаление аккаунтов всех ролей (кроме СуперАдмина)
- Назначение и изменение ролей пользователей
- Установка и сброс временных паролей
- Управление правами доступа для каждого аккаунта
- Контроль лимитов аккаунтов по ролям

#### Контроль данных
- Контроль загрузки данных в блок «Продажи» (в т.ч. из программ бухгалтерского / кассового учёта)
- Контроль загрузки данных в блок «Обучение»
- Валидация и верификация загруженных данных
- Просмотр логов загрузок и действий администраторов

#### Отчёты
- Просмотр всех отчётов системы (продажи, обучение, рейтинги)
- Выгрузка сводных отчётов по всей сети
- Контроль корректности выгружаемых отчётов

#### База знаний и тестирование
- Создание и редактирование баз знаний и тестов
- Просмотр всех материалов и результатов тестирования
- Управление структурой разделов базы знаний

---

### 3.3 Администратор Персонал

**Описание:** Управляет кадровым составом сети — профилями сотрудников, графиками, отпусками и данными по оплате труда.

#### Управление профилями
- Создание и удаление профилей сотрудников
- Редактирование персональных данных (ФИО, контакты, должность)
- Назначение и переназначение сотрудников по точкам / блокам
- Присвоение и изменение ролей в рамках допустимых (Продавец)

#### Табель-графики
- Загрузка и редактирование табель-графиков рабочего времени
- Формирование графиков смен на период
- Контроль фактической отработки

#### Управление отсутствиями
- Отправка сотрудников в отпуск
- Регистрация отгулов и больничных
- Учёт выходов вне графика
- Просмотр календаря отсутствий по подразделениям

#### Оплата труда
- Загрузка персональных данных по оплате труда (ставки, коэффициенты)
- Просмотр сводных данных по ФОТ в разрезе точек / блоков

#### Отчёты
- Выгрузка кадровых отчётов (штатное расписание, текучесть, отработка)
- Просмотр информации о сотрудниках в рамках своих полномочий

---

### 3.4 Администратор Обучение

**Описание:** Управляет образовательным контентом — материалами базы знаний, тестами, назначением обучения и контролем результатов.

#### База знаний
- Создание и редактирование материалов базы знаний
- Управление структурой разделов (4 раздела: организация работы, скрипты, описание продуктов, технологические карты)
- Формирование курсов обучения
- Загрузка медиа-контента (видео, изображения, документы)

#### Тестирование
- Создание и редактирование тестов по материалам разделов
- Настройка параметров тестирования (время, количество попыток, проходной балл)
- Формирование итоговых тестов
- Настройка системы автоматического назначения повторных тестов

#### Назначение обучения
- Назначение обучения и тестов конкретным сотрудникам
- Массовое назначение обучения по группам / точкам / ролям
- Установка сроков прохождения
- Отслеживание прогресса прохождения

#### Рейтинги и отчёты
- Просмотр рейтингов сотрудников по обучению
- Формирование ежемесячных отчётов по результатам обучения
- Выгрузка сводных отчётов по обучению и тестированию
- Просмотр информации о сотрудниках

---

### 3.5 Администратор Продажи

**Описание:** Управляет данными по продажам — планами, фактическими показателями и расчётом мотивации.

#### Планы продаж
- Загрузка данных по планам продаж ежедневного стакана
- Загрузка данных по планам продаж периодического стакана
- Редактирование и корректировка планов
- Распределение планов по точкам и сотрудникам

#### Фактические продажи
- Загрузка фактических данных по продажам (из кассовых систем, 1С и др.)
- Контроль корректности загруженных данных
- Сверка план/факт по точкам и сотрудникам

#### Мотивация
- Загрузка данных для расчёта мотивации по результатам продаж ежедневного стакана
- Загрузка данных для расчёта мотивации по результатам продаж периодического стакана
- Настройка параметров расчёта мотивации (коэффициенты, пороги)
- Контроль корректности расчётов

#### Рейтинги и отчёты
- Просмотр информации о сотрудниках
- Просмотр рейтингов сотрудников по продажам
- Формирование отчётов по мотивации
- Выгрузка сводных отчётов по продажам

---

### 3.6 Руководитель

**Описание:** Руководитель направления или группы торговых точек. Имеет доступ к отчётам и рейтингам по подчинённым точкам и сотрудникам без права редактирования исходных данных.

#### Дашборд
- Сводная панель с ключевыми показателями по подчинённым точкам
- Виджеты: выполнение плана, прогресс обучения, рейтинг сотрудников

#### Отчёты по продажам
- Просмотр каталога отчётов (в рамках своих точек)
- Формирование отчётов по мотивации по продажам ежедневного и периодического стаканов
- Просмотр план/факт продаж по точкам и сотрудникам
- Выгрузка сводных отчётов по продажам

#### Отчёты по обучению
- Просмотр прогресса обучения сотрудников
- Просмотр результатов тестирования
- Просмотр рейтингов по обучению

#### Информация о сотрудниках
- Просмотр профилей сотрудников подчинённых точек
- Просмотр графиков работы
- Просмотр показателей KPI сотрудников

#### Ограничения
- Все данные доступны **только для просмотра** (без права корректировки)
- Видимость ограничена подчинёнными точками / блоками

---

### 3.7 Менеджер блока / куста

**Описание:** Управляющий конкретным блоком (кустом) торговых точек. Видит данные только по своему блоку. Основная задача — оперативный контроль продаж и обучения.

#### Дашборд
- Сводные показатели по точкам своего блока
- Индикаторы выполнения плана продаж
- Статус прохождения обучения сотрудниками

#### Отчёты по продажам
- Просмотр каталога отчётов (в рамках своего блока)
- Формирование отчётов по мотивации по продажам ежедневного и периодического стаканов
- Просмотр план/факт по каждой точке и сотруднику

#### Отчёты по обучению
- Просмотр прогресса обучения сотрудников блока
- Просмотр результатов тестирования

#### Информация о сотрудниках
- Просмотр профилей сотрудников своего блока
- Просмотр графиков работы

#### Ограничения
- Все данные доступны **только для просмотра** (без права корректировки)
- Видимость ограничена своим блоком / кустом
- Доступ к данным **в соответствии с правами, назначенными аккаунту**

---

### 3.8 Продавец

**Описание:** Основной пользователь мобильного приложения. Проходит обучение, тесты, отслеживает свои продажи и мотивацию.

#### Профиль
- Просмотр и редактирование личных данных (фото, контакты)
- Просмотр своего уровня и прогресса
- Просмотр истории достижений и наград

#### База знаний
- Просмотр материалов по 4 разделам: организация работы, скрипты, описание продуктов, технологические карты
- Прохождение назначенных курсов обучения
- Скачивание материалов для офлайн-доступа (если поддерживается)

#### Тестирование
- Прохождение назначенных тестов по материалам разделов
- Прохождение итоговых тестов
- Прохождение повторных тестов (при назначении)
- Просмотр результатов своих тестов

#### Продажи
- Просмотр плана продаж (ежедневный и периодический стаканы)
- Просмотр фактических показателей продаж
- Просмотр расчёта мотивации за текущий и прошлые периоды

#### Рейтинг
- Просмотр собственного рейтинга по продажам
- Просмотр собственного рейтинга по обучению
- Просмотр собственной позиции в общем рейтинге (в рамках блока/сети)

#### Расписание
- Просмотр графика своих смен
- Просмотр информации об отпусках и отгулах

#### Уведомления
- Получение уведомлений о назначенном обучении / тестах
- Получение уведомлений о приближении дедлайнов
- Получение уведомлений о новых материалах в базе знаний

## 7. Технические аспекты реализации

### Хранение роли
Роль пользователя хранится в поле `role` профиля и передаётся в JWT-токене при авторизации.

### Допустимые значения роли

| Код | Название |
|-----|----------|
| `super_admin` | СуперАдмин |
| `root_admin` | Администратор ПО |
| `admin_staff` | Администратор Персонал |
| `admin_education` | Администратор Обучение |
| `admin_sales` | Администратор Продажи |
| `supervisor` | Руководитель |
| `manager` | Менеджер блока / куста |
| `seller` | Продавец |

### Маршрутизация по ролям (фронтенд)

| Роль | Префикс маршрутов | Шаблон (template) |
|------|-------------------|-------------------|
| `super_admin` | `/super-admin/*` | SuperAdminTemplate |
| `root_admin` | `/root-admin/*` | RootAdminTemplate |
| `admin_staff` | `/admin-staff/*` | AdminTemplate |
| `admin_education` | `/admin-education/*` | AdminTemplate |
| `admin_sales` | `/admin-sales/*` | AdminTemplate |
| `supervisor` | `/supervisor/*` | SupervisorTemplate |
| `manager` | `/manager/*` | ManagerTemplate |
| `seller` | `/seller/*` | SellerTemplate (UserTemplate) |

### Проверка прав
Проверка прав осуществляется на двух уровнях:
1. **Фронтенд** — auth guard в `App` компоненте, скрытие UI-элементов по роли
2. **Бэкенд** — middleware проверки роли и области видимости на каждом endpoint
